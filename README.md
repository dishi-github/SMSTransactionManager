# Transaction Manager

An Android application designed to help users track and manage their financial transactions automatically by analyzing SMS notifications.

## Features

- **Automated Tracking**: Automatically detects and parses transaction details from SMS alerts.
- **Transaction Summary**: View detailed reports and summaries of your spending habits.
- **Wishlist**: Keep track of items you want to purchase in the future.
- **Profile Management**: Customize your settings and profile information.
- **Security**: Includes a lock screen feature to keep your financial data private.

## Permissions

This app requires the following permissions to function correctly:
- `READ_SMS`: To automatically detect transaction alerts from your bank or service providers.
- `RECEIVE_BOOT_COMPLETED`: To ensure tracking services start automatically when the device reboots.

## Tech Stack

- **Platform**: Android
- **Language**: Kotlin/Java
- **UI**: XML / AppCompat

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/dishi-github/SMSTransactionManager.git
   ```
2. Open the project in **Android Studio**.
3. Build and run the app on your physical device or emulator.
